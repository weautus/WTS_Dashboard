☁️ Cloud Sync

Keep your app list in sync across all your devices using a GitHub Gist and a personal access token — no extra account needed.

How to set up (one time):
  1. Go to github.com/settings/tokens/new
    • Note: WTS Dashboard sync
    • Expiration: your choice (or "No expiration")
    • Scope: tick gist only
    • Click Generate token and copy it
  2. Create a new Gist at gist.github.com
    • Filename: wts-dashboard.json
    • Content: {"apps":[]}
    • Click Create secret gist
    • Copy the Gist ID from the URL (gist.github.com/<user>/abc123…)
  3. Paste both below and click Test & Save
  4. Repeat step 3 on every device — the token and Gist ID are stored locally only
