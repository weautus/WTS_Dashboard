Paste a GitHub token and the dashboard handles everything else — it finds or creates a private Gist automatically.

One-time setup:
  1. Go to github.com/settings/tokens/new
  2. Give it any name, tick the gist scope, click Generate token
  3. Paste the token below and click Connect
The token is stored only in your browser. Repeat step 3 on each device.
